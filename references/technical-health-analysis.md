## What I Learned from the SeoLoupe References

### Report Structure (top to bottom)
1. **Score Overview** — Large circular score (82/100) with letter grade, plus category cards (Performance, Technical, On-page, Security, Accessibility, AI Ready)
2. **Priority Issues** — Top findings with severity badges (Impact: Medium), effort estimates (Effort: 15 min), and expandable "How to fix"
3. **Locked deeper findings** — "2 more issues are quietly costing you traffic" with upgrade CTA
4. **Page Basics** — Simple pass/fail grid: HTTP Status, Title Tag, Meta Description, Canonical Tag, HTTPS, TLS Health, Indexable, H1 Count, Word Count, TTFB
5. **Crawl Signals** — robots.txt, sitemap.xml, llms.txt, ai.txt, Privacy Policy, Terms of Service, Cookie Policy, CDN, Server
6. **Speed Audit** — Score with key timings (Load Time, TTFB, Page Size, Requests)
7. **Heading Hierarchy** — H1–H6 count grid with hierarchy status assessment
8. **Images & Assets** — Total Images, Missing Alt Text, JSON-LD Blocks, Structured data type
9. **Performance Suggestions** — Each with Grade A–F and description
10. **Weight/Requests by Domain** — Horizontal bar charts
11. **Readability** — Flesch Reading Ease, Avg Words/Sentence, Sentence Count
12. **Locked premium sections** — Connection Timing, Third-Party Impact, File Request Log, Image Optimization, AI Search Visibility

### Key Patterns
- **FREE vs ONE-TIME vs STARTER** tiers shown inline on each section
- **Information density**: Many small metrics in compact grids, not just big score cards
- **Pass/fail indicators**: Green checkmark + "Yes"/red X + "No" pattern
- **Sections continue scrolling**: The report is long and comprehensive, not just 2–3 cards

## Metrics We Are Currently Missing

These are visible in SeoLoupe but our crawler does **not** collect:

| Missing Metric | SeoLoupe Section | Effort to Add |
|---|---|---|
| **H1–H6 heading counts** | Heading Hierarchy | Requires htmlParser.ts changes — parse `<h1>`–`<h6>` elements |
| **Image count + missing alt text** | Images & Assets | Requires htmlParser.ts changes — parse `<img>` elements |
| **Structured data / JSON-LD detection** | Images & Assets | Requires htmlParser.ts changes — parse `<script type="application/ld+json">` |
| **HTTPS / TLS verification** | Page Basics | Can be partially derived from URL protocol, but TLS health needs network check |
| **CDN detection** | Crawl Signals | Requires response header inspection (`Server`, `Via`, `CF-Ray` headers) |
| **Server technology detection** | Crawl Signals | Requires response header inspection (`Server` header) |
| **Flesch Reading Ease / readability** | Readability | Requires text analysis on body content (word count exists, but not sentence count) |
| **Open Graph / social tags** | (Priority Issues in SeoLoupe) | Requires htmlParser.ts changes — parse `og:*` and `twitter:*` meta tags |
| **llms.txt / ai.txt** | Crawl Signals | Requires checking for these specific files during crawl |
| **Privacy Policy / ToS / Cookie Policy links** | Crawl Signals | Requires link text analysis or URL pattern matching |

**None of these require database schema changes** — they all need `htmlParser.ts` enhancements and corresponding `crawledPages` column additions (or new columns).
