## A-to-Z Rebrand Plan

### Phase 1: Production Configuration (Category 2)
Change all page titles, meta descriptions, JSON-LD, and `og:site_name` to VerseSEO. This is the highest-impact change for search engines and social sharing.

**Files:** `Layout.astro`, `index.astro`, `app.astro`, `login.astro`, `register.astro`

### Phase 2: User-Facing Branding (Category 1)
Replace all visible "Foundable" text with "VerseSEO" across the marketing site, dashboard UI, FAQ, demo scanner, and dynamic report strings.

**Files:** `Navbar.astro`, `Footer.astro`, `AuthForm.astro`, `AppSidebar.astro`, `DemoScanner.astro`, `FAQ.astro`, `ProductFlow.astro`, `SearchEverywhere.astro`, `GrowthGraph.astro`, `LiveAuditSimulator.astro`, `app-shell.ts`

### Phase 3: Comments and Docs (Categories 1 + 5)
Update developer-facing comments, `AGENTS.md`, and `DEPLOYMENT.md`. Low priority but keeps codebase consistent.

**Files:** `GrowthGraph.astro`, `ProcessingLoader.astro`, `AGENTS.md`, `DEPLOYMENT.md`

### Phase 4: Scratch/Diff Cleanup (Category 5)
Delete or ignore `diff_app_shell.txt` and `dev/null` — they're build artifacts/dumps, not source.

### Phase 5: Internal Identifiers (Category 4) — Coordinate Carefully
Rename `foundable:scan-complete` → `verseseo:scan-complete` and `foundable:select-project` → `verseseo:select-project` across all dispatchers/listeners simultaneously. Rename `foundable_session` cookie only when ready to invalidate all existing sessions.

**Files:** `app-shell.ts`, `LiveAuditSimulator.astro`, `backend/src/auth/session.ts`

### Phase 6: Backend / DB (Category 3) — Separate Deployment
Change Reddit User-Agent, Postgres credentials in Docker/deploy config. Requires coordinated backend deployment and DB migration.

**Files:** `backend/src/config/env.ts`, `backend/.env.example`, `DEPLOYMENT.md`
